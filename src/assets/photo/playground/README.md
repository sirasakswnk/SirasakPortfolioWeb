# Playground assets

พื้นที่ภาพสำหรับเกมส่วนตัวและงานทดลองในหมวด Playground โดยยังไม่มีเกมจริงถูกเลือกมาแสดง

- สร้างโฟลเดอร์แยกแต่ละเกม เช่น `<game-id>/` และเก็บภาพสำหรับเว็บใน `<game-id>/optimized/`
- เตรียมภาพปกหนึ่งภาพ และภาพ gameplay/lobby/results ตามฟีเจอร์ที่มีจริงประมาณ 1–3 ภาพ
- เก็บสัดส่วนและความละเอียดต้นฉบับ พร้อมระบุภาพสาธิตหรือข้อมูลจำลองตามจริง
- ไม่ใช้ภาพของเกมอื่นเป็นตัวอย่างบนเว็บจริง และไม่ใส่ลิงก์ placeholder
- เพิ่มข้อมูลที่ยืนยันแล้วใน `src/data/playground.js` โดยใช้โครงสร้างเดียวกับ `src/data/projects.js`
- ชื่อไฟล์นำเข้าและขนาดภาพในข้อมูลต้องตรงไฟล์จริง

การ์ด Playground แสดงชื่อ คำอธิบายสั้น ป้าย Personal project สถานะ (ถ้ามี) เทคโนโลยีสูงสุด 2 รายการ และลิงก์ Play demo/GitHub เฉพาะ URL แบบ HTTP/HTTPS ที่ระบุไว้

เปิดรายละเอียดและภาพผ่าน dialog เดิมของ Portfolio ข้อมูล `role`/`roleDescription` และ `technologies` ที่ยังไม่ได้ยืนยันสามารถเว้นไว้ได้ โดยใช้ `null` หรือ array ว่างตามชนิดข้อมูล ระบบไม่แสดงหัวข้อว่าง

ยังไม่มีการ commit หรือ publish รายการเกมใดจากการเตรียมโครงสร้างนี้
