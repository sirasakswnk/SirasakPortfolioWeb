# โปรเจคถัดไป

พื้นที่เตรียมภาพและข้อมูลสำหรับโปรเจคที่สี่ ยังไม่มีรายการนี้ในหน้า Portfolio

## ข้อมูลที่ต้องเตรียม

- ชื่อโปรเจค:
- คำอธิบายสั้น ๆ ว่าทำอะไรหรือแก้ปัญหาอะไร:
- ลิงก์ GitHub หรือเอกสารอธิบายโปรเจค:
- ลิงก์ Demo สาธารณะ (ถ้ามี):
- สถานะปัจจุบัน:
- ทำคนเดียวหรือเป็นทีม (จำนวนคน):
- ส่วนที่รับผิดชอบ:
- เทคโนโลยีที่ใช้จริง:
- ฟีเจอร์เด่นที่ต้องการโชว์:

เว้นข้อมูลที่ยังไม่ได้ยืนยันไว้ก่อน และใช้ลิงก์เฉพาะที่พร้อมให้ผู้เข้าชมเปิดได้

## ภาพ

- วางภาพต้นฉบับไว้ในโฟลเดอร์นี้ โดยเก็บความละเอียดเดิม
- เตรียมภาพหน้าจอที่แสดงฟีเจอร์เด่นประมาณ 3–6 ภาพ เลือกตามลักษณะงานจริง
- ภาพปกสามารถส่งเป็น `cover.png` หรือให้จัดจากภาพหน้าจอที่เตรียมมา
- ภาพรวมระบบ `system-overview.svg`/`.png` เป็นตัวเลือกสำหรับงานที่ต้องการอธิบายสถาปัตยกรรม
- รูปหน้าคอมแนะนำความกว้าง 1440–1920px ส่วนภาพมือถือเก็บสัดส่วนแนวตั้งเดิม
- ตั้งชื่อภาพให้สื่อความหมาย เช่น `dashboard.png` หรือ `main-feature.png`
- โฟลเดอร์ `optimized/` ใช้เก็บภาพสำหรับเว็บหลังตรวจและเลือกภาพแล้ว

## เมื่อนำขึ้นเว็บ

เพิ่มรายการใน `src/data/projects.js` หลังยืนยันเนื้อหา บทบาท และเลือกภาพแล้ว
กำหนดขนาดภาพตามไฟล์จริง พร้อม alt และ caption โดยใช้ `featured: false`
เพื่อแสดงต่อจากโปรเจคเดิม ระบบกริด รายละเอียด และป๊อปอัปภาพรองรับรายการเพิ่มอยู่แล้ว
